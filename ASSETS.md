# Asset provenance

## Visuals

The following raster assets were generated for this project with ImageGen.
The repository's MIT grant applies to original project materials to the extent
of the contributors' rights. Third-party package rights are documented in
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

| File | Dimensions | Use |
| --- | --- | --- |
| `public/assets/cockpit-frame.png` | 1585 × 992 RGBA | Selected realistic cockpit concept, edited with transparent windshield and blank areas for live displays and controls |
| `public/assets/asphalt.jpg` | 1254 × 1254 | Seamless, evenly lit airport asphalt texture without markings |
| `public/assets/grass.jpg` | 1254 × 1254 | Seamless olive/sage airfield grass texture |
| `public/assets/sky.jpg` | 1774 × 887 | Equirectangular sunny sky and cloud panorama |
| `public/assets/tree.png` | 1024 × 1536 RGBA | Isolated coastal pine with transparent background |
| `public/designs/cockpit-*.png`, `*.webp` | Various | Original generated cockpit design alternatives and optimized gallery previews |
| `docs/images/*.png` | Various | Screenshots of the running game |

The cockpit frame is pre-rendered; instruments and controls are live. Exterior
terrain, runway markings, lights, buildings, static aircraft and vegetation
placement are generated by Three.js code. No real airport model or geographic
dataset is used. UI icons come from Phosphor Icons.

## Speech

The game includes **145 mono MP3 files** at 24 kHz / 48 kbps:

- `public/assets/radio/`: 62 Chinese dialogue clips and 21 shared English
  height/safety callouts.
- `public/assets/radio/en/`: 62 English pilot/tower dialogue clips.

These are synthetic recordings of fictional exchanges. Callsigns, training
frequency, airport, clearances and emergencies are game scenarios.

| Role | Chinese dialogue | English dialogue |
| --- | --- | --- |
| Tower | `zh-CN-XiaoxiaoNeural`, +24%, −12 Hz | `en-US-AriaNeural`, +22%, −6 Hz |
| Pilot | `zh-CN-YunxiNeural`, +26%, −18 Hz | `en-US-GuyNeural`, +24%, −10 Hz |
| Shared safety/height calls | `en-US-GuyNeural`, +6%, 0 Hz | Same files |

Clips were synthesized using edge-tts and filtered/normalized using FFmpeg.
They are outputs, not voice models. Provider software, voice-model rights and
service terms are not conveyed by this repository's MIT license. See
[third-party notices](THIRD_PARTY_NOTICES.md).

Text, measured durations and cache fingerprints are in `game/src/comms/`.
The optional `ops/generate-radio.py` tool can regenerate recordings. Initial
MAYDAY/PAN PAN declarations contain three complete units from the same pilot
voice as the following report; `ops/verify-radio-prefixes.py` checks waveforms.

Runtime playback is entirely self-hosted. Web Audio adds radio band limiting,
compression, distortion, gated static and PTT clicks; clean safety calls have
priority. Engine, wind, rolling, reverse-volume and contact effects are
procedurally synthesized in `game/src/audio/soundscape.js`.
